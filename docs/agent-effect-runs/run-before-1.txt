**The endpoint** (`backend/app/api.py`, right after `get_collection`):
- **Returns** the collection's prompts newest first, in the same `{"prompts": [...], "total": n}` shape as `GET /prompts`.
- **Returns 404** `{"detail": "Collection not found"}` if the collection doesn't exist. `GET /prompts?collection_id=<id>` returns an empty list for an unknown id instead. With the 404, an empty list here always means an existing collection that has no prompts.

| `test_list_collection_prompts_not_found` | An unknown id gives 404 with the right message |
