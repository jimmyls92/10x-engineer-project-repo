**The endpoint** (`backend/app/api.py`, `list_collection_prompts`, under the Collection banner):
- **It returns the same shape as `GET /prompts`**: a list of prompts plus a `total` count, sorted newest first.
- **An unknown collection id returns 404** `{"detail": "Collection not found"}`. That's deliberate: `GET /prompts?collection_id=` returns an empty list for an unknown id, but here the id is in the path, so the project's rules make it a 404. A comment above the route says why.
- **An existing collection with no prompts returns 200** with an empty list.
- I also changed the `get_collection` docstring, which pointed readers to `GET /prompts?collection_id=` for a collection's prompts. It now points to the new route.
