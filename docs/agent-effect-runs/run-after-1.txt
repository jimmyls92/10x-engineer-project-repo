I added `GET /collections/{collection_id}/prompts` and four tests for it. The suite passes: **23 passed**, 4 of them new. The 54 warnings come from the dependencies and the known deprecations in `models.py`, nothing I added.

**The endpoint** (`list_collection_prompts` in `backend/app/api.py`, under the Collection Endpoints banner):

- It returns the same `{prompts, total}` shape as `GET /prompts`, newest first.
- **An unknown collection gives 404** (`"Collection not found"`). This is different from `GET /prompts?collection_id=<unknown>`, which returns an empty list with 200. The project's rule is that an id in the path must exist, while a filter in the query string that matches nothing is not an error.
- **An existing collection with no prompts** gives 200 and an empty list.
- I also updated the `get_collection` docstring, which used to point readers to `?collection_id=`; it now points to the new route.
